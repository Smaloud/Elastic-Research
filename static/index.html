怎样使用

  1. 选择 Ollama 或兼容接口，保存后测试连接。
  2. 回到资料库，在论文卡片上点击“LLM 提取”。
  3. 逐项审核术语、方法、数据集、发现、局限与建议标签。
  4. 只有接受的建议标签会写入检索标签。
数据边界 Ollama 在本机处理；云端接口会把论文文本发送给你配置的服务商。
